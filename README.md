# Дурак

Карточная игра «Дурак» для Android на движке Godot 4.7: подкидной и переводной, от 2 до 6 игроков,
3D-стол с живыми соперниками, которые сами кладут карты на стол.

## Где взять игру

- **Проверить в браузере (на телефоне):** https://timnuri.github.io/durak/
- **Приложение (APK):** раздел **Releases** справа → `durak.apk`.

Обе версии собираются автоматически после каждого изменения (вкладка **Actions**, 5–15 минут).

## Как устроен проект

- `game/` — проект Godot.
  - `scripts/core.gd` — правила, проверка настроек и компьютерные соперники (без экрана).
  - `scripts/table3d.gd` — 3D-стол: комната, лампа, стол, карты, анимации.
  - `scripts/person.gd` — соперник: модель человека со скелетом, сидит, держит веер карт, тянется рукой к столу.
  - `scripts/main.gd` — меню, настройки, оформление, ход партии, мои карты.
  - `tests/` — проверки (правила против эталона, партии ботов, снимки экрана).
- `tools/make_traces.js` — записывает эталонные партии из старого проверенного ядра на JavaScript.
- `.github/workflows/build.yml` — автосборка.
- `android/release.keystore` — ключ подписи (пароль `durak2026`, alias `durak`). Не терять: обновления ставятся поверх только с ним.
