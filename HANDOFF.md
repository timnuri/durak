# Дурак — записи для продолжения работы

Сюда записываются все изменения и решения, чтобы в новом чате было видно, что сделано и что нет.

## Решения
- Делаем на **Godot 4.7.2**, сборка на GitHub Actions (как `timnuri/shooter3d`): APK в Releases и версия для браузера на GitHub Pages.
- Старая веб-версия (JavaScript + three.js) больше не развивается. Из неё взяты только проверенные правила (перенесены в `core.gd`) и картинки карт.
- Рендер (с 09.11.2026): `forward_plus` на ПК, `mobile` на Android, `gl_compatibility` в браузере (`project.godot`). Код смотрит `renderer` / `hi_quality()` в `table3d.gd`: размытие фона (DOF), мягкие тени, SSAO — только где поддерживается.
- Соперники — модель Xbot со скелетом, **тёмные силуэты** (решение Тима 09.11: силуэт или вообще убрать). Одежда раскрашена в коде по костям (`person.gd`, `_dress`), но затемнена до силуэта. Сидят в креслах. Руки по IK.
- Чтобы ничего не выдать: соперник берёт **случайную** карту из веера, новые карты попадают в случайное место веера, карты из колоды летят к игроку без руки.
- Стол **только квадратный** (решение Тима 09.11; выбор формы убран из «Оформления», `pref.shape` всегда `square`). Соперники сидят дугой на дальней стороне стола (не по кругу), чтобы все были в кадре; камера сама подбирает высоту/отступ: головы соперников вверху экрана, ближний край стола над моими картами (`frame_camera`).
- Мои карты — 2D внизу экрана: нажать или перетащить на стол. Если можно сходить по-разному — нажать карту, потом карту на столе или «Перевести».
- Темы: Кабинет, Казино, Неон, Светлая. Колоды: Винтаж, Русские, Покерные. Рубашки: 5 цветов.
- Онлайн: пока только кнопка с окном «скоро».

## Отзыв Тима после версии с фото-фоном (09.11.2026, 10:19) и план
Тим: «фон комнаты огромный, стол и карты скучные, модели — чёрные манекены, карты плохо видно из-за ракурса, нет реалистичности; выглядит как Java-игра для кнопочных телефонов». В шутере (`timnuri/shooter3d`) красиво: глубина, свет, графика.
Почему шутер красивый: профессиональный уровень из `godotengine/tps-demo` (PBR-текстуры, карты нормалей, запечённый свет) + рендер `forward_plus` / `mobile` (на вебе `gl_compatibility`). В Дураке всё самодельное из простых фигур + `gl_compatibility`.
План переделки (следующий шаг):
1. Рендер как в шутере: `rendering_method="forward_plus"`, `.mobile="mobile"`, `.web="gl_compatibility"`; на Android — свечение, размытие фона (DOF), мягкие тени, HDRI-отражения.
2. Настоящая 3D-комната вместо фото-плоскости: модели из `KhronosGroup/glTF-Sample-Assets` (качают через git, сайты типа polyhaven/kenney заблокированы): SheenWoodLeatherSofa, GlamVelvetSofa, ChairDamaskPurplegold / SheenChair (стулья у стола), StainedGlassLamp (лампа), GlassHurricaneCandleHolder (свеча), DiffuseTransmissionTeacup (чашка), GlassVaseFlowers / DiffuseTransmissionPlant (растения), Lantern. Лицензии CC-BY/CC0 — указать в README.
   HDRI для отражений: `godotengine/godot-demo-projects/3d/material_testers/backgrounds/lobby.hdr` или `night.hdr`; текстура дерева там же (`test_materials/texture_wood.png`).
3. Стол: PBR-дерево с картой нормалей и блеском, стулья вокруг.
4. Ракурс: ниже наклон, чтобы карты на столе читались (как в старом 2D: крупные карты в центре), фон размыт DOF.
5. Соперники: не голые манекены — либо модели в одежде (искать на GitHub: Mixamo-персонажи из примеров three.js — Michelle с родной текстурой, Soldier; readyplayer.me — проверить лицензию), либо показывать как на фото: руки с веером в фокусе, тело размыто и в тени.

## Как проверять у себя (в чате Claude)
- **Скачать Godot напрямую отсюда нельзя** (GitHub releases отвечает 504). Обход: ветка `get-godot` в репозитории — её сборка кладёт `godot.zip` в эту же ветку; забрать: `git fetch origin get-godot && git checkout origin/get-godot -- godot.zip`. Если ветку удалили — создать заново (файл `.github/workflows/get-godot.yml`, запуск на push в ветку `get-godot`).
- Рендер `mobile` / `forward_plus` здесь МОЖНО снимать: программный Vulkan `VK_ICD_FILENAMES=/opt/lavapipe/lvp_icd.json`, `--rendering-driver vulkan --rendering-method mobile`.
- Godot скачивается с GitHub releases: `tools/ci_install_godot.sh`.
- Снимки экрана: `xvfb-run ~/godot/godot --rendering-driver opengl3 --path game -s res://tests/shots.gd --resolution 390x844 -- /tmp/out cabinet 3`.
- Правила против эталона: `node tools/make_traces.js <старое ядро core/> /tmp/traces.json 450`, потом `godot --headless --path game -s res://tests/test_core.gd -- /tmp/traces.json`.
