# Дурак — записи для продолжения работы

Сюда записываются все изменения и решения, чтобы в новом чате было видно, что сделано и что нет.

## Решения
- Делаем на **Godot 4.7.2**, сборка на GitHub Actions (как `timnuri/shooter3d`): APK в Releases и версия для браузера на GitHub Pages.
- Старая веб-версия (JavaScript + three.js) больше не развивается. Из неё взяты только проверенные правила (перенесены в `core.gd`) и картинки карт.
- Рендер `gl_compatibility` везде (Android, Web): одинаковая картинка, работает на слабых телефонах, и её можно снимать скриншотами без видеокарты.
- Соперники — настоящие модели людей (Xbot, Michelle) со скелетом, тёмные, как силуэты при свете лампы. Руки двигаются по IK (`person.gd`).
- Чтобы ничего не выдать: соперник берёт **случайную** карту из веера, новые карты попадают в случайное место веера, карты из колоды летят к игроку без руки.
- Стол овальный (вытянут вглубь) или прямоугольный; игроки рассажены равномерно; камера сама подбирает угол и расстояние, чтобы все были видны над моими картами.
- Мои карты — 2D внизу экрана: нажать или перетащить на стол. Если можно сходить по-разному — нажать карту, потом карту на столе или «Перевести».
- Темы: Кабинет, Казино, Неон, Светлая. Колоды: Винтаж, Русские, Покерные. Рубашки: 5 цветов.
- Онлайн: пока только кнопка с окном «скоро».

## Сделано (09.11.2026)
- `core.gd`: правила (подкидной/переводной, кто подкидывает, лимиты, порядок добора, скрытый козырь, обмен козыря, ничьи), проверка настроек с готовыми исправлениями, боты (новички/опытные/мастера).
  Проверено: 450 эталонных партий (44 тыс. ходов) совпали ход в ход со старым ядром (`tests/test_core.gd` + `tools/make_traces.js`).
- 3D-стол, комната с огнями, лампа с тенями, модели людей сидят и держат веер, анимации: положить карту, побить, перевести, забрать, бито, раздача.
- Меню, «Новая игра» (соперники 1–5, режим, сила, колода, карт на руках, «Все правила»), «Оформление», «Как играть», пауза, конец партии, сохранение партии, кнопка «Назад» Android.

- Автотест `tests/autoplay.gd`: 6 полных партий через интерфейс (2–6 игроков, переводной, скрытый козырь, обмен козыря) — все доиграны.
- Первая сборка на GitHub прошла: APK в Releases, браузерная версия на Pages.

## Как проверять у себя (в чате Claude)
- Godot скачивается с GitHub releases: `tools/ci_install_godot.sh`.
- Снимки экрана: `xvfb-run ~/godot/godot --rendering-driver opengl3 --path game -s res://tests/shots.gd --resolution 390x844 -- /tmp/out cabinet 3`.
- Правила против эталона: `node tools/make_traces.js <старое ядро core/> /tmp/traces.json 450`, потом `godot --headless --path game -s res://tests/test_core.gd -- /tmp/traces.json`.
